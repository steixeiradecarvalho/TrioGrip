# Contribuir

Abra uma issue descrevendo o gesto que falhou ou a peça que não saiu, antes do patch grande.

Pull requests úteis:

- correção de strum / tilt / latência em Android antigo
- sync de pulso na LAN sem transportar áudio
- acessibilidade do grip (canhoto, alvos, contraste)
- síntese mais barata que soe melhor

Evite:

- loja de samples na nuvem
- login
- framework que impeça abrir `app.html` num servidor estático
- “IA que toca no seu lugar”
